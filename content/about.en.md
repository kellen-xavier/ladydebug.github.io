About this blog!

Hi, I'm Kellen. My goal with this blog is to keep a record of my notes so I can
consult them later: revisit an installation guide or a tool, remember how I used
it when I wrote about it, and return to those notes with updates and things I've
learned. I also want to improve my writing and practice explaining things.

This blog is not the ultimate tutorial or a source of absolute truth. I will
always cite the references I used. Feel free to [open an issue here](https://github.com/kellen-xavier/ladydebug.github.io/issues)
to point out an error.

Feel free to use the template as a reference.
Some of my inspirations are this [technology blog](https://akitaonrails.com/)
and a [blog I read when I was 15](https://www.depoisdosquinze.com/). Following
them for some time gave me the desire, and the need, to create my own.
You can find the template I started with [here](https://themes.gohugo.io/).
